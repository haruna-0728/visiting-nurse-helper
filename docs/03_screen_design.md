## 1. Screen Overview（画面概要）

本ツールはStreamlitによる単一画面構成である。画面上部から順に、免責事項（disclaimer）、タイトル、症状選択、所見入力、判定ボタン、判定結果、の順に配置している。

---

## 2. Operation Flow（操作フロー）

1. 患者が訴えている自覚症状を、画面上部のセレクトボックスから選択する
2. 選択した症状に紐づく所見の入力欄が表示される（通常の所見は検索絞り込み＋3列表示、専用スケールが必要な所見は個別の入力欄）
3. 観察した所見の程度を入力する（未入力の所見は「なし」として扱われる）
4. 「緊急度を判定する」ボタンを押す
5. 全体の緊急度、および疾患候補ごとの内訳（緊急度別にグルーピング）が表示される

---

## 3. Field Definitions（項目定義）

| 項目 | 入力形式 | 補足 |
| --- | --- | --- |
| 自覚症状の選択 | セレクトボックス | `ALL_SYMPTOMS`のキー一覧から選択 |
| 通常の所見 | 所見名で絞り込む検索欄＋3列のセレクトボックス（なし／軽度／中等度／高度） | 専門的な観察手技を要する所見には、選択欄のヘルプに観察方法・リスクの目安を表示（SIGN_HELP） |
| 意識レベル低下 | JCS／GCSを切り替える専用入力欄 | 選択したスケールのスコアから内部Severityへ変換 |
| 褥瘡評価 | NPUAP/EPUAP分類（判定に使用）＋DESIGN-R®2020の6項目（記録用のみ） | DESIGN-R®の合計点は判定には使用しない |
| MMT評価 | 右／左それぞれ0〜5点のセレクトボックス | 悪い方の点数、および左右差の大きさの、いずれか重い方の重症度を採用 |
| 血圧高値 | 収縮期／拡張期の数値入力（mmHg） | 日本高血圧学会のガイドライン相当の区分で重症度へ変換 |

## 4. Result Display（判定結果の表示）

- 全体の緊急度を、色（🔴🟡🟢）とマイルドな文言（「病院受診・緊急要請の必要性が高い状態です」等）で表示する
- 疾患候補ごとの内訳は、緊急度別に「🔴 直ちに受診・緊急要請」「🟡 医師へ報告」「⚪ 経過観察相当」にグルーピングして表示する
- 🔴・🟡は常に表示し、⚪（経過観察相当・所見に乏しいもの）は`st.expander`で折りたたみ、件数を見出しに表示する（判定結果の一覧が長くなりすぎないための配慮）
- 疾患候補名にすでに「疑い」が含まれる場合は、表示上「疑い」を二重に付与しない
- 特定の疾患候補には、追加の案内文（CONDITION_GUIDANCE）を表示できる
